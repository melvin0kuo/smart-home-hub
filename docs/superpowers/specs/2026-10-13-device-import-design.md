# Home Assistant 裝置匯入精靈

目標：一般使用者可在網頁選擇 HA 已整合的實體、命名及指定房間，加入首頁，不需手寫映射。使用者已授權直接設計、實作與驗證，不另設設計確認關卡。

第一版以一個 HA Entity 建立一張卡片，明確標示實體；多實體合併、品牌登入及網路掃描另列後續工作。後端沿用設定好的 HA 連線，透過官方 REST API 取得狀態及服務清單。僅白名單的 light、switch、camera 與溫度／濕度／電量／功率 sensor 可匯入；其他類型顯示限制。

匯入預設唯讀。可選「重要電源保護」，此時不允許測試或開放控制。基本開關只有使用者明確確認負載安全、逐次點選開啟及關閉測試，且兩個方向都收到新狀態，才可於十分鐘內以可控制方式匯入。測試不自動還原，畫面顯示最後狀態，提醒使用者自行恢復。測試不包含亮度、色溫、隱私、PTZ 及任意 service。狀態回報確認不代表獨立實體硬體測量。

既有映射中的實體（包括受保護插孔）全部禁止重複匯入及精靈測試。後端重新取得候選，不信任瀏覽器提供能力。SQLite 以模式＋Entity 唯一鍵保存匯入映射，批次原子交易；既有私有映射檔不修改。重啟恢復匯入裝置，即時同步沿用 HA WebSocket。

Mock Mode 使用明確標示的獨立示範候選，測試及匯入不觸碰 HA。所有匯入 API 僅管理員可用，寫入保留 Session、Origin 與 CSRF 驗證；不輸出 HA 原始屬性、憑證或影像網址。離線可唯讀匯入，控制測試禁止。

介面使用三步驟面板：選取實體、名稱／房間／保護及選擇性測試、檢視結果。手機單欄，平板與桌面候選列表兩欄，保留返回及錯誤重試。

驗收：身份與參數防護、重複及並行匯入、離線、逾時、狀態未更新、唯讀保護、秘密過濾、重啟恢復皆有測試；前後端測試、Lint、Build 通過；實際 HA 僅做唯讀探索。

實機清單探索後補強：通用 switch 可能是設定而非電源，因此測試需先讀取 HA Entity Registry，分類為一般實體且未隱藏／停用才可開放。設定、診斷、分類未知，以及自動更新／自動關閉／韌體／重啟／隱私／偵測／童鎖相關實體固定唯讀；分類讀取失敗時也保持唯讀。
