# HA OS App Implementation Plan

**Goal:** 將既有網頁及 FastAPI 封裝成可安裝的 HA OS App。
**Architecture:** 固定公開 source commit 的多階段 Docker 建置，App options → 安全啟動設定 → 持久化單一後端。
**Spec:** ../specs/2026-10-16-ha-os-app-design.md

- [x] 先寫設定轉換、秘密持久化、來源檢查測試並觀察失敗。
- [x] 實作 App 設定、啟動程式、固定來源 Dockerfile 及 repository metadata。
- [x] 本機測試與 Docker 建置，確保不打包私人資料。
- [x] 更新使用文件並審查；在樹莓派安裝、唯讀驗證，保留回復途徑。

約束：繁體中文文件、單 worker、禁止公開秘密、不改重要電源、不宣稱未實測藍牙移植完成。使用者已授權直接實作，不新增設計確認關卡。

## 驗證紀錄

- 後端 100 項、前端 28 項測試與 Ruff／ESLint 通過；Docker 多階段包含前端 Build，GitHub CI 通過。
- amd64 容器啟動、登入及未授權拒絕通過；Linux 0600 權限與無效設定不洩漏秘密日誌通過。
- 獨立審查未發現阻擋缺陷；審查指出的 Linux／容器／實機缺口已補驗證。
- Supervisor 安裝等待超時時實際 ARM64 建置仍繼續；檢查日誌及已安裝狀態後確認成功，沒有重複安裝。
- 樹莓派 aarch64 原生建置、Real HA、六張卡片、唯讀重要電源、App 重啟與既有 Session 持久化均通過；開機自動啟動已啟用。未重啟整台樹莓派，亦未操作電器。
- 直接 BLE、電腦歷史資料庫移轉及樹莓派私人 VPN 尚未完成，原電腦服務保留。
