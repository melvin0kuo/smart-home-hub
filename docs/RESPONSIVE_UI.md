# 響應式介面調整

2026-10-12

## 資訊與操作流程

- 家庭總覽呈現設備統計、需要留意的設備、已設定情境、裝置控制與最近紀錄。未接入的感測器及無功率資料的設備不顯示空白統計卡片。
- 裝置清單依房間篩選及名稱／型號搜尋；切換主頁面時重設搜尋與房間，避免攝影機或插座頁被舊條件隱藏。
- 總覽及裝置清單的攝影機只顯示狀態與入口，完整隱私開關、影像與十字方向控制集中於攝影機頁；影像仍需使用者主動播放。
- 詳細整合資訊收進可展開區塊。已送出的紅外線或旋轉指令顯示「已送出」，不誤報為操作失敗或狀態確認。
- 插孔 2、3 仍維持既有唯讀映射及鎖定，不修改裝置授權或配對。

## 各裝置版面

| 寬度 | 版面 |
| --- | --- |
| 小於 768px | 手機：固定底部導覽、單欄裝置、插孔逐列排列、影像與控制上下排列；更多選單包含插座與用電／整合狀態。 |
| 768–1199px | 平板：精簡固定側欄、雙欄裝置；900px 起攝影機影像與控制並排，直向較窄時改為上下排列。 |
| 1200px 起 | 桌面：完整側欄、多欄裝置與獨立攝影機工作區；1600px 起一般裝置使用三欄。 |

控制按鈕至少 44px 高，手機方向按鈕 52px；開關保留大於視覺尺寸的觸控範圍。保留深色／淺色模式、鍵盤焦點與停用狀態。

## 驗證

- 前端單元測試 7 項通過，含總覽攝影機不掛載影像或 PTZ 控制的回歸測試。
- ESLint、TypeScript 與 Vite Build 通過；仍有既有的大型 bundle 提示。
- 私人 HTTPS 網址以 320、390、768、1024、1440px 寬度檢查，沒有頁面橫向溢出。
- 實際瀏覽器檢查底部導覽、更多選單、搜尋、切頁重設條件、平板攝影機並排與插孔鎖定；未切換真實電器、隱私模式或發送紅外線指令。
- 現有 Playwright Mock E2E 的標題斷言已更新；此次未執行該套會操作電器的測試（目前服務為 Real Mode）。
- 螢幕尺寸以瀏覽器模擬；仍需使用者在實際手機、平板確認觸控手感及瀏覽器安全區域。
