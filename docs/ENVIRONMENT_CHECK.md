# 新環境檢查清單

公開版本不附私人主機與網路盤點。自行檢查作業系統、Python 3.12+、Node 24／npm、Git；Windows 建議 PowerShell 7。Docker／Compose 與 Bluetooth 為選用。

Real Mode 需 HA 類型、URL、版本、備份、專用 Token、可互通設備網路與 Entity。BLE 另查硬體、距離、主機／容器權限。Mock 不需 HA、Docker 或藍牙。

開發實測 Windows、Python 3.14.4、Node 24.15.0、HA Container 2026.10.1；樹莓派、arm64 與平台容器待獨立驗證。這是測試紀錄，不代表使用者已具備環境。
