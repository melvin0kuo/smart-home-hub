# 跨品牌新增裝置方向

本平台新增裝置的目標是讓使用者匯入自己的產品，而非僅支援開發者家中的型號。通用路徑為「在 Home Assistant 加入品牌整合 → 本平台辨識標準能力 → 選取實體及設定房間 → 驗證可控制能力 → 加入首頁」。目前已實作第一版 [HA 匯入精靈](DEVICE_IMPORT.md)。

## 現有邊界

- 品牌與型號不是通用匯入的允許條件；支援由 HA Entity 類型、單位、服務及分類決定。
- 基本開關可經使用者測試開放，支援單位的感測值可直接唯讀顯示。
- 多實體合併、廠商帳號登入、Matter 配對、MQTT 探索及 ONVIF 新增流程尚未實作。
- 不支援的產品顯示限制，不會以模擬控制冒充整合成功。

## 後續工作順序

1. 以 HA Device／Entity／Area Registry 建立實體分組，取得廠商、型號及房間，讓一台實際設備產生一張主卡片。
2. 增加標準能力轉接器：light 調光／色溫、fan 風速／擺風、climate 模式／目標溫度、humidifier 目標濕度、cover 開合等。每項需驗證服務參數、範圍、模式相依及回報確認。
3. 建立品牌／協定目錄，顯示由 HA 支援的設定入口與準備步驟，清楚區分已安裝、可設定、需要硬體及不支援。
4. 為具有可靠設定流程的整合接上官方授權或 HA 配對流程。帳號權限授予、重置及解除配對由使用者明確確認。
5. 在需求及可維護性足夠時提供獨立 MQTT／ONVIF 等 Provider，沿用統一設備契約與權限，不讓前端依賴品牌協定。

每個轉接器需描述可探索的類型、設定需求、能力映射、操作白名單、狀態確認、錯誤診斷及驗證證據。單一設備專屬擴充不能覆蓋通用裝置的操作保護。以上為規劃，不是已支援功能清單。
