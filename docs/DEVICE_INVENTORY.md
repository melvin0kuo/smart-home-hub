## 能力驗證紀錄格式

每個設備／子單元／能力各一份紀錄，不能只填「全台成功」。

| 欄位 | 內容 |
| --- | --- |
| 設備與子單元 | 例如延長線第 1 孔；不能混同全機 |
| 能力／來源整合 | 例如 switch／Matter |
| Entity 清單位置 | 本機私有紀錄路徑；公開文件不含秘密 |
| 讀寫／單位／範圍／scope | outlet／whole_device、W／kWh／K／% |
| 測試日期／測試者 | 待實測 |
| 控制操作授權範圍 | 哪個安全負載、哪些開關或移動 |
| 測試輸入與上游回應 | 去除秘密 |
| 後續 HA 狀態與延遲 | 是否達成目標狀態、是否過期 |
| 實體觀察與狀態信心 | confirmed／inferred；IR 特別區分 |
| 斷線／恢復測試 | 方法、結果與風險 |
| 結果與證據位置 | 通過／失敗／未測，附私有證據位置 |
| 平台是否可啟用 | 逐能力放行，不由型號自動啟用 |
